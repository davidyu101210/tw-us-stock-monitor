台股＋美股自動看盤 v1.0 混合版

台股：
- 不使用 TradingView Widget
- 自己畫 K 線
- 支援 5/15/30/60 分與日 K
- MA5 / MA20
- 成交量
- TWSE 三大法人
- 法人連買與分數

美股：
- 使用 TradingView Widget
- 不需要 Twelve Data / Alpaca Key

第一次：
1. 完整解壓縮
2. 雙擊 setup.bat
3. 再雙擊 start.bat

注意：
台股行情使用公開免費來源，可能延遲，不是券商逐筆即時。


美股法人新增：
- 讀取公開機構持股資料
- 顯示最新申報日期
- 近一季 VWAP
- 13F 申報 Value / Shares 隱含價
- 法人推估成本價
- 可信度

重要：
13F 不會公開真實買進價格，所以美股的法人推估成本只能當參考區，不是實際成本。


v1.0 美股法人強化：
- 中文欄位
- 加碼 / 減碼燈號
- 持股比例
- 持股數量中文化
- 機構加碼數 / 減碼數
- 法人集中買進分數 0~100
- 整體法人偏多/偏弱判定

v1.0 台股功能對齊：
- 盤前 / 盤中 / 盤後 / 休市狀態
- 法人推估成本價
- 現價距法人推估成本 %
- 法人集中買進分數
- 近10日加碼/減碼燈號
- 外資/投信連買
- 法人最後更新日期

注意：台股法人是 TWSE 盤後日報，盤中不會逐筆更新。
