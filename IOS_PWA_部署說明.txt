台美股自動看盤 v1.2 - iPhone PWA 版

這一版是「網頁 App」：
- iPhone Safari 可開啟
- 可加入主畫面
- 可全螢幕使用
- 不需要 App Store
- 不需要 Windows 電腦一直開著（部署到雲端後）

建議部署方式：
1. 把整個專案放到 GitHub
2. 用 Streamlit Community Cloud 部署
3. Main file path 選 app.py
4. 部署完成會得到一個 https 網址
5. iPhone 用 Safari 開啟該網址
6. 點 Safari 分享按鈕
7. 選「加入主畫面」
8. 之後桌面會出現一個看盤 App 圖示

iPhone 功能：
- 台股 / 美股切換
- 盤前 / 盤中 / 盤後狀態
- 法人 / 機構推估成本
- 法人集中買進分數
- 加碼 / 減碼判定
- 手機版響應式排版
- 自動更新

注意：
- 台股法人資料是 TWSE 盤後日報
- 台股價格仍使用公開免費來源，可能延遲
- 美股 TradingView 是否即時取決於 TradingView 資料授權


v1.2 新增：
- 美股 13F 每日自動檢查
- 顯示 13F 最後檢查時間
- 顯示最新 13F 申報日期
